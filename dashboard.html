Pasarela de pago (Wompi) de este agente

Conecta la cuenta Wompi de ESTE agente para que genere links de pago en el chat y cierre sus ventas. Cada agente tiene su propia pasarela y catálogo. Deja en blanco para no cambiar la llave actual. Configura el webhook Wompi hacia https://auvro.netlify.app/.netlify/functions/pago-webhook con tu events secret.

Notificaciones comerciales

Recibe avisos por correo (Gmail conectado en Integraciones de este agente) cuando tu agente genere un link de pago, cuando se apruebe un pago o cuando cambies el estado de un lead. En cada envío se usa la cuenta Gmail conectada vía Composio.

Catalogo de productos de este agente (venta en chat)

Tipos: Físico, Digital, Servicio, Suscripción (con variantes como 1/3 meses) y Tour (tarifas por pasajero según edad, descuento por tamaño de grupo y extras). El total lo calcula el servidor en el chat: el agente solo recoge la composición del grupo.

Pipeline de ventas (estados)

Crea tus estados. Marca cuál es el estado de venta cerrada para que el pago aprobado la cierre automáticamente.

Importar catálogo
